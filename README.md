# 🧩 Full Stack Practice Project – Next.js 16 / Express / Prisma / PostgreSQL

## 🚀 Overview

This repository is a **full-stack practice project** designed to learn modern web development using the following stack:

| Layer    | Technology                                           | Notes                                         |
| -------- | ---------------------------------------------------- | --------------------------------------------- |
| Frontend | **Next.js 16 + React 19 + TypeScript + TailwindCSS** | App Router enabled, React Compiler active     |
| Backend  | **Express + Prisma + PostgreSQL**                    | REST API with authentication and CRUD         |
| Auth     | **JWT (HttpOnly cookies)**                           | Register, login, logout, and protected routes |
| Database | **PostgreSQL 16+**                                   | Managed via Prisma ORM                        |
| Styling  | **TailwindCSS**                                      | Utility-first CSS framework                   |

The goal is to **build and deploy a functional app** where authenticated users can access a dashboard and perform CRUD operations on “Client” records.

---

## 🧱 Project Structure
